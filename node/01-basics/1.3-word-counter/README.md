# תרגיל 1.3 · מונה מילים

## הרצה

```bash
node counter.js sample.txt   # יוצר report.json בתיקייה הנוכחית
node counter.js nope.txt     # הודעת שגיאה ברורה, בלי stack trace
npm test
```

## משתני סביבה

אין.

## החלטות מרכזיות

- הלוגיקה (`analyze.js`) מופרדת מה-CLI (`counter.js`): את הפונקציה הטהורה בודקים על מחרוזות, בלי קבצים.
- `readFile` מ-`fs/promises` עם `await` ברמה העליונה של המודול (top-level await עובד ב-ES Modules).
- מילים מזוהות עם `/[\p{L}\p{N}']+/gu`: `\p{L}` תופס אותיות בכל שפה, כולל עברית, וזה עדיף על `\w` שמכיר רק אנגלית. לפני הספירה מורידים הכל לאותיות קטנות, כך ש-`The` ו-`the` נספרות יחד.
- שורה אחרונה ריקה (newline בסוף הקובץ) לא נספרת כשורה נוספת.
- `try/catch` סביב הקריאה, עם הודעה מיוחדת ל-`ENOENT`. משתמשים ב-`process.exitCode = 1` ולא זורקים שגיאה, כך שהתהליך מסתיים בקוד שגיאה ובלי stack trace.
- `report.json` הוא פלט שנוצר בהרצה, ולכן הוא ב-`.gitignore`.
