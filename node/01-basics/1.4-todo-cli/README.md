# תרגיל 1.4 · CLI לניהול משימות

## הרצה

```bash
node todo.js add "לקנות חלב"
node todo.js list
node todo.js done 1
node todo.js remove 1
node todo.js foo      # פקודה לא מוכרת: עזרה
npm test
```

המשימות נשמרות ב-`tasks.json` בתיקייה שממנה מריצים (הקובץ ב-`.gitignore`).

## משתני סביבה

אין.

## החלטות מרכזיות

- `tasks.js` אחראי רק על קריאה ושמירה עם `fs/promises`, ו-`todo.js` רק על הפקודות. קובץ שעוד לא קיים (`ENOENT`) נחשב לרשימה ריקה; כל שגיאה אחרת נזרקת הלאה.
- מזהה חדש הוא המזהה הגבוה ביותר ועוד 1, ולא אורך המערך. אחרי `remove` לא נוצרים שני מזהים זהים.
- `Number(id)` לפני ההשוואה: כל מה שמגיע מ-`process.argv` הוא מחרוזת, ו-`"1" === 1` הוא `false`.
- `switch` עם `default` שמדפיס עזרה מכסה גם פקודה לא מוכרת וגם הרצה בלי פקודה.
- כל בדיקה רצה בתיקייה זמנית חדשה (`mkdtempSync`) ומריצה את ה-CLI כתהליך אמיתי. כך כל בדיקה מתחילה עם `tasks.json` ריק, והבדיקות לא נוגעות בקובץ האמיתי.
