## החלטות מרכזיות

- named exports (`export function add`) ולא `export default`: מי שמייבא כותב בדיוק את השמות שהוא צריך, והעורך משלים אותם אוטומטית.
- ב-ES Modules חובה לכתוב את הסיומת בייבוא יחסי: `./math.js`, לא `./math`.
- `average([])` מחזיר 0 בבדיקה מפורשת בתחילת הפונקציה. בלי הבדיקה מקבלים `0 / 0`, שזה `NaN`.
- הבדיקות מייבאות את הפונקציות ישירות, כך שאפשר לבדוק לוגיקה בלי להריץ את `app.js`.
