# תרגיל 1.1 · שלום Node

## הרצה

```bash
node hello.js דנה   # גרסה, מערכת הפעלה, תאריך וברכה אישית
node hello.js       # בלי שם: הוראות שימוש במקום ברכה
npm test            # בדיקות עם node:test
```

## משתני סביבה

אין.

## החלטות מרכזיות

- `process.argv` הוא מערך: `[0]` הוא הנתיב ל-node, `[1]` הנתיב לסקריפט, והארגומנט הראשון של המשתמש הוא `process.argv[2]`.
- `process.version` ו-`process.platform` זמינים תמיד; את הפרטים המלאים על מערכת ההפעלה נותן המודול המובנה `node:os`. הקידומת `node:` מבהירה שזה מודול מובנה ולא חבילה מ-npm.
- `"type": "module"` ב-`package.json` מאפשר `import` במקום `require`.
- הבדיקות מריצות את הסקריפט כתהליך נפרד (`execFileSync`) ובודקות את הפלט, כי זה בדיוק מה שהמשתמש רואה.
